# 🍽️ Restaurant Landing Page

A responsive and modern restaurant landing page built using **HTML, CSS, JavaScript, and Bootstrap**.

## 🌐 Live Demo

🔗 [View Live Website](https://varsha0521.github.io/restaurant-landing-page/)

## 📌 About the Project

This project is a responsive restaurant landing page designed to provide a clean and attractive user experience.

The website includes different sections to showcase the restaurant, its menu, services, and contact information. Bootstrap was used to create a responsive layout, while JavaScript adds basic interactivity.

## ✨ Features

- 🏠 Responsive home/hero section
- 🍴 Restaurant menu section
- 📖 About section
- ⭐ Services/features section
- 📱 Fully responsive design
- 🖱️ Interactive navigation
- 🎨 Modern and clean UI
- 📩 Contact section
- ⚡ JavaScript-based interactions
- 📐 Bootstrap responsive components

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and custom design
- **JavaScript** – Interactivity and dynamic behavior
- **Bootstrap** – Responsive layout and components
